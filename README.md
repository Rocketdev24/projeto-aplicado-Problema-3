# projeto-aplicado-Problema-3

Esse repositório é para o terceiro problema da cadeira de Projeto Aplicado III, denominado: **Quando chove, por onde se chega à UBS?**

## Estrutura

- `docs/` — enunciado e materiais de apoio do problema
  - `Problema3_PA3_CC.pdf` — enunciado oficial do problema
  - `croqui.pdf` — croqui do bairro (Vila Nova Esperança)
  - `Perguntas_croqui.pdf` — perguntas sobre o croqui
  - `Problema3.md` — divisão de papéis, prazos e metas de estudo do grupo
- `dados/` — arquivos de entrada para testes e medições
  - `LEIA-ME.txt` — descrição dos arquivos de dados
  - `pequeno.txt` / `pequeno_esperado.txt` — caso de teste pequeno com respostas esperadas
  - `pequeno_criticos.txt` / `pequeno_criticos_esperado.txt` — caso de teste da pontuação extra (CRÍTICOS)
  - `cargas/` — arquivos de carga (1.000, 5.000, 20.000 e 50.000 pontos) para o relatório de desempenho
